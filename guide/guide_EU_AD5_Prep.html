Votre espace personnel de révision en ligne

EU AD5 Prep est une application web qui fonctionne directement dans votre navigateur — sans installation, sans compte, sans abonnement. Vos scores, fiches et progression sont sauvegardés automatiquement sur votre appareil. Chaque utilisateur dispose d'un espace personnel persistant : le navigateur vous reconnecte automatiquement à la prochaine visite.

🔑 Votre identifiant stable — simple et mémorisé automatiquement

Chaque utilisateur possède un identifiant stable basé sur son prénom. Le navigateur mémorise le dernier utilisateur connecté et le reconnecte automatiquement à la prochaine visite.

🔗 romaricponcin.github.io/AD5/#u=Tamina
📌 La partie bleue = adresse commune à tous les utilisateurs
🟢 La partie verte = votre prénom — identifiant stable, lisible, partageable entre appareils
👤 Tamina → #u=Tamina
👤 Romaric → #u=Romaric
👤 Julie → #u=Julie
👤 Milan → #u=Milan

🔄 Nouvel appareil / cache vidé

La progression est stockée localement. Pour la transférer :

1

Option A — URL : ouvrez #u=Tamina sur le nouvel appareil → l'espace s'affiche mais vide (le localStorage est propre)

2

Option B — Export JSON : sur l'ancien appareil → 📥 Export profil → envoyez-vous le fichier → importez-le sur le nouvel appareil ✅

⚠️
À retenir : l'URL #u=Tamina identifie votre espace mais ne contient pas vos données. Seul l'export JSON transfère votre progression complète entre appareils.

💡
Conseils pour progresser
  • Chaque jour : 10 Q entraînement + 5 Q simulation sur la catégorie du jour
  • Mode simulation : respectez le chrono pour s'habituer à la pression du concours
  • Tags de révision : après chaque réponse, taguez 🔴/🟡/🟢 pour cibler vos révisions
  • Session rapide ⚡ : bouton dédié aux 5 questions où vous avez le plus d'erreurs
  • Fiches UE : créez une fiche après chaque thème étudié pour ancrer les connaissances
  • Calendrier : cochez chaque jour de révision pour maintenir votre série 🔥
  • Export hebdomadaire : sauvegardez votre profil JSON chaque vendredi soir
🎯
Pour importer de nouvelles questions : Menu « Mon profil » → champ « Importer questions depuis URL » → collez une URL GitHub Gist. Vos scores existants ne sont jamais effacés.
